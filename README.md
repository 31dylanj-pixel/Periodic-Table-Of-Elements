# ⚛️ Periodic Table of Elements

An interactive and modern Periodic Table of Elements built with HTML, CSS, and JavaScript.

The project is designed to make learning and exploring the periodic table more intuitive through an interactive interface, color-coded element categories, and detailed element information.

## ✨ Features

- Interactive periodic table containing all 118 elements
- Atomic numbers, symbols, names, and atomic masses
- Color-coded element categories
- Interactive element detail modal
- Element descriptions
- Common ionic charges
- Common isotopes
- Electron shell information
- Valence electrons
- Electronegativity
- Noble-gas electron configurations
- Atomic properties
- Physical properties
- Melting and boiling points
- Discovery year
- Responsive design
- Modern glassmorphism interface
- Dark navy-themed design

## 🧪 Element Categories

Elements are organized into ten color-coded categories:

- **Alkali Metals**
- **Alkaline Earth Metals**
- **Transition Metals**
- **Post-transition Metals**
- **Metalloids**
- **Nonmetals**
- **Halogens**
- **Noble Gases**
- **Lanthanides**
- **Actinides**

## 🎨 Design

The project uses a modern dark interface featuring:

- Dark navy gradients
- Glassmorphism cards
- Subtle borders and shadows
- Smooth hover animations
- Montserrat typography
- Color-coded element categories
- Responsive layouts
